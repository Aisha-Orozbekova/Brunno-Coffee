# BRUNO Coffee

A responsive, single-page website for a fictional neighborhood coffee shop in Bishkek. It is built with plain HTML, CSS, and JavaScript, with no dependencies or build step.

## Run the site

- Open `index.html` directly in a browser, or
- Open the folder in VS Code and launch `index.html` with the Live Server extension.

The page is also ready for GitHub Pages: publish this folder from the repository's root using **Settings → Pages**.

## What is included

- Responsive navigation, coffee menu with category filters, photo gallery, café story, and contact details.
- A light/dark theme switch that remembers the selected theme in local storage.
- Accessible contact form validation and a clearly labeled demo-only success message. Form data is not sent or stored.
- A scroll-to-top button, skip link, semantic sections, and reduced-motion support.

## Content to customize

BRUNO Coffee and its business details are fictional. Replace the sample address, opening hours, prices, email, social links, and map location with verified information before using the page for a real business. The contact form is front-end only; connect it to a backend or form service if submissions should be received.

Photos are loaded from Unsplash and require an internet connection. Each image element has a neutral background color behind it so the layout remains usable if an image cannot load. Google Fonts are also optional; Georgia and system sans-serif fallbacks are provided.
